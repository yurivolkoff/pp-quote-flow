    View 3 — the quote document. 4 states × delivery calculated or not, plus an unresolvable link.
  • A1 — The reference number is the h1, with a real issued date and a real expiry date. Never "subject to change" — procurement cannot cite a quote it cannot name.
  • A2 — "Prepared for" names the requester, because the person reading this is often the approver the link was forwarded to.
  • A3 — The expired state never silently re-prices: the table dims, a "prices as of" caption appears, and the CTA becomes "Get an updated quote" under a new number. PDF and print stay enabled so an old PDF still resolves.
  • A4 — "Need changes?" reopens the PDP with the configuration restored and says out loud that a change produces a new quote number.
  • A5 — Print calls the real print stylesheet: pressing Print anywhere in this prototype renders view 5. One template, so the page and the PDF cannot drift.
  • A7 — "Invalid link" answers a bad token with a recovery path and a phone number, never a bare 404.
  • A6 — Every action carries a text label, never an icon alone; the line-item table is a real table with a caption and scoped headers, and stacks to label/value rows on mobile with no horizontal scroll.
